# 算法限制、调参与比赛排障

## 调参顺序

1. **先校准采样链**：直流偏置、增益、时钟实际频率；使用 `sigf32_linear_calibrate`。
2. **后定采样率和缓冲长度**：频率分辨率约为 `fs/N`；低频测量靠更长记录，不靠“更复杂的 FFT”。
3. **滤波再测量**：先用 `tools/design_filter.py` 设计 SOS/FIR，再把系数写入静态数组；每次改系数重新验证通带增益、稳定性、群延迟。
4. **按用途选窗**：幅值优先 Flat-top，通用频率分析 Hann，强动态范围 Blackman-Harris；明确相干增益与 ENBW。
5. **PLL/FLL**：FLL 用于捕获；PLL 的 `kp` 先小、`ki` 更小。出现摆动先减 `kp`，稳态频偏再缓慢增 `ki`。
6. **LMS/NLMS**：先从小 `mu` 开始；观察误差信号。若权值发散，降低 `mu`、检查参考和 desired 的极性、优先 NLMS。

## 指标适用条件

| 指标 | 最低条件 | 常见误用 |
|---|---|---|
| 过零频率 | 至少两个可靠正向过零，阈值高于噪声 | 削顶/多谐波波形直接过零 |
| RMS | 记录覆盖多个周期或固定积分窗口 | 把 DC 偏置当 AC 幅值 |
| THD/THD+N | 明确基波、足够分辨率和动态范围 | 非整周期时不加窗、把泄漏当谐波 |
| 相位 | 同步采样、足够 SNR | 两个 ADC 非同步或通道延迟未校准 |
| I/Q | 本振频率接近信号、低通稳定 | 低通未收敛就读取幅相 |
| 传递函数 | 输入有足够激励且输出未削顶 | 单段 `coherence=1` 当成可信度证明 |

## 现场排障表

| 现象 | 优先检查 | 处理 |
|---|---|---|
| 频率跳变 | 采样时钟、阈值、比较器毛刺 | 用同步 ADC，增大阈值或中值去毛刺；FLL 失锁时不更新显示 |
| FFT 旁瓣很高 | 非整周期、窗、削顶 | 加窗、增大 N、检查 ADC 是否满量程 |
| 幅值偏小 | 窗 coherent gain、前端增益 | 使用库的窗补偿；做两点增益标定 |
| 相位不稳定 | ADC 同步、SNR、低通时间 | 使用同一 SOC；延长 I/Q 低通稳定时间 |
| PLL 不锁 | 初值/带宽过大、输入太小 | 先 FLL 捕获，减小 kp/ki，检查相位单位是 pu 而非 rad |
| LMS 发散 | μ 太大、参考错误 | 降低 μ，改用 NLMS，限制输入和检查误差信号极性 |
| DMA 缓冲错乱 | ping-pong 所有权、ISR 太长 | 在完成中断只交换指针；CPU 绝不处理正在 DMA 写入的块 |

## 性能记录

不要假设 “1024 点 FFT 固定 2–3 ms”。请在目标时钟、RAM/Flash 放置、优化等级和实际 ISR 负载下，用 GPIO 翻转或 CPU cycle counter 记录：算法周期、最大栈、RAM、DMA 丢块数和中断抖动。把结果写入自己的比赛硬件记录表。
