# F280049C API 调用手册扩建设计

## 目标

把现有 API 索引扩展为可以直接照抄、编译和接入 ADC/DMA 处理链的中文手册。公开接口以 `include/sigf32.h` 为唯一事实来源，不改变算法 ABI。

## 文档结构

1. `docs/API参考.md`：逐个公开函数的权威参考。
2. `docs/API调用教程.md`：按实际任务组织完整调用流程。
3. `examples/api_usage/`：教程中引用的可编译 C 示例。

每个 API 条目固定包含：原型、功能、参数逐项说明、单位与范围、状态/工作区生命周期、返回值、输出有效性、调用上下文、最小示例、常见错误。结构体字段也逐项解释。

## 场景教程

- ADC 标定、去直流、毛刺与限幅诊断。
- FIR、SOS IIR、抽取与块处理。
- RMS、频率、幅值比、相位和亚采样时延。
- 窗函数、Goertzel、频谱指标与工作区分配。
- NCO/DDS、I/Q 解调、PLL/FLL 与失锁处理。
- LMS/NLMS 及 50 Hz 噪声抵消。
- 扫频复数传递函数。
- CPU/TMU/CLA/C2000Ware RFFT 后端选择。

所有示例使用静态数组和调用者工作区，不使用动态内存。硬件章节说明 `ADC/DMA -> 算法 -> 显示/DAC` 的调用位置，但在没有自制板原理图时不写封装脚号。

## 验证

- 从公开头文件提取符号，与 API 参考中的反引号函数名核对。
- `examples/api_usage/*.c` 使用主机 GCC `-Wall -Wextra -Werror` 编译。
- F280 目标相关后端继续使用 TI C2000 编译器条件编译验证。
- Markdown、UTF-8、链接和占位符扫描通过。

## 非目标

不修改算法实现和公开函数签名；不编造真机 benchmark；不指定尚未确定的 ADC/DAC/GPIO 封装脚号。
