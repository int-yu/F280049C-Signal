# 快速开始（F280049C）

## 工具版本

- DigitalPower SDK / C2000Ware：`26.01.00.00`
- TI C2000 C28x Compiler：`25.11.1.LTS`
- CCS：安装上述组件的版本

工程的 `products="sysconfig"` 明确保留。导入前请在 CCS 的 Products 中确认 `COM_TI_DIGITAL_POWER_C2000WARE_SDK_SOFTWARE_PACKAGE_INSTALL_DIR` 已指向 DigitalPower SDK 安装目录。

## 导入与 SysConfig

1. CCS 选择 **File → Import CCS Projects**，导入 `F280049C_Signal.projectspec`。
2. 首次选择 `CPU1_RAM`，双击 `main.syscfg` 并以 SysConfig Editor 打开。
3. 建立 ePWM SOCA → ADC SOC → ADC ISR 或 DMA 的同步链；调通后再使用 `CPU1_FLASH`。
4. 在 `main.c` 的 ADC ISR/DMA 完成回调调用算法。不要在 ISR 中 `printf`、动态分配或访问慢速外设。

`sigf32.c`、`sigf32.h` 与三个 `backends/c2000/*.c` 已列入 projectspec。只需要把所需算法状态和数组定义为静态对象。

## 最小测量链

```c
#include "sigf32.h"

static sigf32_dc_blocker_t dc;
static float fir_state[17];
static const float fir_coeffs[17] = { /* 用 tools/design_filter.py 生成 */ };
static sigf32_fir_t fir;

void signal_init(void) {
    sigf32_dc_blocker_init(&dc, 0.995f);
    sigf32_fir_init(&fir, fir_coeffs, 17U, fir_state, 17U);
}

float signal_sample(float adc_volts) {
    float x = sigf32_linear_calibrate(adc_volts, 1.0f, 0.0f);
    x = sigf32_dc_blocker_process(&dc, x, 0);
    return sigf32_fir_process(&fir, x);
}
```

对 block 算法（FFT、频率、THD）优先采用 DMA ping-pong 缓冲：DMA 填满一个 buffer 后让 CPU/CLA 处理该 buffer，同时 DMA 填另一个。不得在 DMA 正在写入的 buffer 上做 FFT。

## 相位与采样率

- 所有 `*_hz` 参数单位 Hz，`sample_rate_hz` 必须是实际采样率。
- 库内部相位为 per-unit 周期 `[0,1)`；`0.25` 等于 `90°`。用 `sigf32_phase_pu_to_deg/rad` 仅在显示边界转换。
- 目标频率到 100 kHz 时，ADC 采样率、抗混叠滤波器和运算预算必须满足设计。一般至少 5–10 个样点/周期，频谱测量需更高记录长度。

PowerShell：

```powershell
gcc -std=c11 -Wall -Wextra -Werror -Iinclude tests/test_signal.c src/sigf32.c -lm -o tests/test_signal.exe

```

主机测试验证数值回归，不等于 ADC/ePWM/DMA 真机时序验证。
## 启用 C2000Ware RFFT 后端

主机回归使用 `sigf32_rfft_reference()`；真机使用官方 FPU DSP 库时，在编译 `backends/c2000/sigf32_rfft_adapter.c` 时定义 `SIGF32_ENABLE_C2000WARE_RFFT`，再调用 `sigf32_rfft_c2000ware()`。工程模板已加入 `fpu32/fpu_rfft.h` 的搜索目录和 `c28x_fpu_dsp_library_eabi.lib` 链接。`input`、`output`、`twiddles` 各由调用者提供 `fft_size` 个 `float`，并按 C2000Ware 文档对齐；`real`、`imag` 各提供 `fft_size/2+1` 个元素。此路径已用 TI C2000 编译器 25.11.1.LTS 显式启用宏编译验证。
