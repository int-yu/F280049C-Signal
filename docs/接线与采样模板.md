# 逻辑接线与采样模板

本模板不指定引脚号。自制板原理图确认后，只需在 `main.syscfg` 补 pin map，不修改算法 API。

| 逻辑信号 | 建议外设 | 模拟前端/连线要求 | 算法用途 |
|---|---|---|---|
| 主信号 `VIN_SIG` | ADC A/B | 单极性 ADC 输入必须加中点偏置；串联限流/保护，RC 抗混叠；满量程不得超过 ADC 参考范围 | 采样、RMS、FFT、滤波 |
| 同步参考 `VIN_REF` | 同步 ADC 或 CMPSS | 与主信号共享采样时钟；需要相位时使用同步 ADC SOC | I/Q、相位、传递函数 |
| 过零 `ZERO_CROSS` | CMPSS → eCAP/XBAR | 比较器阈值与迟滞由模拟幅度决定；隔离噪声，确认逻辑电平兼容 | 周期捕获/FLL 备用 |
| 激励 `DAC_A`/`DAC_B` | DAC + 缓冲 | F280049C 仅两路 DAC；输出后加重建滤波及运放驱动 | DDS、I/Q 激励、扫频 |
| 触发 `PWM_SOC` | ePWM SOCA/SOCB | ADC 与 DAC 更新以同一个定时基准触发；记录具体时刻 | 相干采样、DMA 数据链 |

## 模拟前端检查表

1. 计算 ADC 输入的最大正负摆幅和偏置，确认任何瞬态都不碰电源轨。
2. 抗混叠低通的截止要低于 `fs/2`，且在目标频段内平坦；不可只依赖数字滤波。
3. ADC 参考电压、偏置基准、DAC 参考应低噪声并有正确去耦。
4. 双通道相位测量必须使用同步 SOC；顺序采样的固定时间差应校正或避免。
5. ePWM 触发、ADC acquisition window、转换完成、DMA 搬运和算法处理必须画出时序并测量。

## SysConfig 最小配置

- Clock Tree：先确定 CPU/ADC 时钟。
- ePWM：固定周期产生 ADC SOC；如需 DAC 同步，再产生更新事件。
- ADC：配置 SOC 通道、采样保持窗口和 ADCINT/DMA 触发。
- DMA：ping-pong 缓冲；启用中断仅做 buffer 切换，不在 ISR 做长 FFT。
- CMPSS/eCAP（可选）：把过零输出路由到捕获模块，保存时间戳。

硬件噪声、地回流、运放稳定性和 ADC 驱动阻抗会直接限制算法结果；软件不能补救削顶、混叠或不同步采样。
